APA 7 Statistics Reporting

Report the number, in the right notation, with the correct italics and decimals. Everything that follows is APA 7.

① Report it exactly like this

AnalysisReport as
t-testt(df) = 2.02, p = .047, d = 0.45
ANOVAF(dfb, dfw) = 5.62, p = .005, η² = .11
Chi-squareχ²(df, N = 120) = 6.31, p = .012, V = .23
Correlationr(28) = .42, p = .021
Regression (b)b = 0.52, SE = 0.14, β = .28, t = 3.71, p < .001
Regression (model)R² = .34, F(2, 97) = 25.1, p < .001
MeansM = 3.45, SD = 0.82

Correlation df = N − 2. ANOVA df: k−1 between, N−k within.

② In a sentence

Sleep-deprived participants recalled fewer words (M = 6.2, SD = 2.1) than rested participants (M = 7.4, SD = 2.3), t(78) = 2.02, p = .047, d = 0.45.

The shape: what you found, in plain words → the descriptives → the test statistic → p → the effect size. The stats go after the finding, not instead of it. Save “what it means” for the Discussion. Full patterns: §3.2.

③ Italics: slanted or upright?

Italic (Latin letters): t, F, r, p, M, SD, N, n, df, d, b, SE, z, U, R², V.
Upright (Greek letters & numerals): η², χ², β, ρ, α, ω², and every digit.

Rule of thumb: Latin letter → italic; Greek letter → upright. The subscripts and the numbers themselves are never italic.

④ The p-value, done right

• Report the exact p to two or three decimals: p = .03, p = .048.
• Below .001, write p < .001 — don't chase more zeros.
• No leading zero: p = .04, never 0.04 (it can't exceed 1).
• Two-tailed unless you say otherwise.
• A significant p is a decision, not a size — always pair it with an effect size, ideally a CI.

⑤ Decimals & leading zeros

QuantityDec.Lead 0?

Drop the leading zero only when the value can't exceed 1. *Means/SDs: match the scale's precision. Convert your own numbers with the APA formatter.

The one mistake to never make

p = .000 is not a thing. SPSS prints Sig. = .000, but a probability is never exactly zero — that's rounding. Write p < .001. And skip p = 0, “p = ns”, and pasting the software's default five-decimal soup. Report the exact value, not the asterisks.
