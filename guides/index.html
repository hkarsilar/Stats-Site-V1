Statistics Guides

A lesson teaches one idea. A guide walks one job, from the file you were handed to the paragraph you hand in. These five are the long ones, written for the evening when something is due and the lesson you need is three lessons deep.

Each guide is self-contained and heavily cross-linked: when a step needs a concept, it links to the lesson that teaches it, so you can go as deep as you have time for and no deeper. Three of the five work on a real file from the practice datasets, which means every number on the page can be reproduced on your own machine rather than taken on trust.

The five guides

🧭 Choosing Statistics for Your Dissertation Three boring questions, asked in the right order, and the test names itself. Plus the honest advice about messy designs that flowcharts leave out. 🧹 Clean Your Survey Data, Step by Step Raw questionnaire export to analysis-ready file in eight steps: validation, missing data, reverse-coding, composites, reliability. 📊 Analyze Your Thesis Data in JASP The whole path in free, point-and-click software: open the CSV, check assumptions, run the test, read the APA sentence off the output. 📄 From SPSS Output to APA Results Annotated output for the five classic analyses, with the reportable cells highlighted, the classic misreading named, and the exact sentence to write. 🎓 One Study, Start to Finish The capstone: one 2×2 study carried through question, design, power, cleaning, assumptions, ANOVA, effect sizes and the finished write-up.

Which one do you need?

If you do not yet know what analysis your data wants, start with Choosing Statistics. If you know the test but your file is a mess, start with Clean Your Survey Data. If you have output on screen and a blank Results section, go straight to From SPSS Output to APA. And if you want to watch all of it happen once, in order, on one dataset, read One Study, Start to Finish and follow along.

Looking for something shorter? The Statistics Toolbox holds the calculators, printable cheat sheets and reference tables, and the course itself covers every concept these guides lean on, one interactive lesson at a time.
